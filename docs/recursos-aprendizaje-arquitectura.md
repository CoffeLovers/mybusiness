## 3. 🏛️ Arquitectura de Software

11. **[Fundamentals of Software Architecture (Capítulo Gratuito) — Richards & Ford](https://www.thoughtworks.com/content/dam/thoughtworks/documents/books/bk_Fundamentals_of_Software_Architecture_Free_Chapter_en.pdf)**  
    Decisiones arquitectónicas, trade-offs, modularidad y evaluación de características de arquitectura (-ilities).
12. **[Architecting Software the SEI Way — Carnegie Mellon University](https://www.sei.cmu.edu/documents/5455/2012_018_101_24228.pdf)**  
    Enfoque formal del Software Engineering Institute sobre el impacto social, económico y técnico de las decisiones arquitectónicas.
13. **[Fundamentals of Software Engineering — Nate Schutta](https://www.thoughtworks.com/insights/books/fundamentals-software-engineering-book)**  
    Principios de ingeniería y evolución de programador a arquitecto de software.
14. **[Head First Software Architecture — ThoughtWorks](https://www.thoughtworks.com/en-us/insights/books/head-first-software-architecture)**  
    Aproximación visual e intuitiva a los componentes y desacoplamiento de sistemas.
15. **[Software Architecture Introduction (Parte 1)](https://www.youtube.com/watch?v=8UlLgOf20Ho)**  
    Fundamentos, drivers de arquitectura y vistas arquitectónicas.
16. **[Software Architecture Fundamentals — Estilos Arquitectónicos](https://www.youtube.com/watch?v=kVmzBUMbVko)**  
    Microservicios, Event-Driven Architecture, Space-Based y Monolitos Modulares.
17. **[Introducción Completa a la Arquitectura de Software (Español)](https://www.youtube.com/watch?v=JKMsYLxbnpM)**  
    Patrones arquitectónicos aplicados en la industria explicados en español.
18. **[Curso de Arquitectura de Software — UNMSM](https://www.youtube.com/watch?v=8f-71FA48vk)**  
    Clase universitaria detallada sobre el proceso y modelado de arquitecturas de software.
19. **[Arquitectura del Software — EscuelaIT / DesarrolloWeb](https://www.youtube.com/watch?v=MbX0hGRiJm8)**  
    Fundamentos teóricos, cohesión, acoplamiento y clean architecture.

## 🛠️ Proyecto Práctico Recomendado: API de E-commerce / Fintech

Para consolidar estos conceptos en el código de **MyBusiness**:

- **Autenticación & RBAC**: JWT, roles y Refresh Tokens cifrados.
- **Transaccionalidad & Idempotencia**: Cuentas, pagos y deduplicación de eventos.
- **Persistencia Aislada**: Patrón Database-per-Service con Drizzle ORM y PostgreSQL.
- **Caché y Event Bus**: Redis Pub/Sub y BullMQ para procesamiento asíncrono.
- **Trazabilidad y ADRs**: Registro inmutable de auditoría y documentación de trade-offs técnicos.
